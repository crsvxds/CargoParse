# Customs Data Consolidator (ВЭД Китай) 🚀

Автоматизированное рабочее место (АРМ) для верификации таможенных деклараций и консолидации кодов маркировки. Программа сопоставляет реестр артикулов с выгрузками кодов из Excel, фильтрует дубликаты внутри файлов и собирает финальный отчет в формате `.xlsx`.

## ✨ Основные возможности

* **Асинхронный движок (Threading):** Обработка тяжелых Excel-файлов происходит в отдельном потоке. Интерфейс программы не зависает и остается отзывчивым.
* **Умный поиск деклараций:** Автоматически сопоставляет артикул с файлами из папки (поддерживает маски вида `артикул`, `артикул-1`, `артикул-2` и т.д.).
* **Локальный контроль дубликатов:** Исключает повторяющиеся коды маркировки строго в рамках каждого отдельного файла, предотвращая порчу данных.
* **Мгновенное логирование:** Подробный разбор хода верификации (включая вывод полных дублирующихся кодов) выводится в GUI-окно в реальном времени с возможностью сохранения в `.txt`.
* **Автоматическое форматирование:** Итоговый Excel-файл автоматически подгоняет ширину колонок и выравнивает текст по сетке для удобства чтения.

## 🛠 Технологический стек

* **Язык:** Python 3.x
* **Интерфейс:** Tkinter (GUI)
* **Анализ данных:** Pandas, OpenPyxl

## 📂 Структура входных данных

### 1. Файл артикулов (`articles.txt`)
Текстовый файл в кодировке UTF-8. Каждая строка должна содержать параметры, разделенные пробелами. Структура строки:
`[Артикул] [Наименование...] [Описание] [Грузовые места] [Количество] [Ед. изм]`
